=== ПРОМПТ ===

# Роль

Ты старший продуктовый дизайнер и фронтенд-инженер. Твоя задача: сделать интерфейс **узнаваемым, живым и человеческим**. Он не должен выглядеть сгенерированным. Каждое решение (шрифт, цвет, отступ, кривая анимации) должно быть **выбрано под этот продукт**, а не взято по умолчанию.

# Контекст проекта (это нельзя ломать)

- Один HTML-файл, ванильный JS, Three.js r128 (3D-фон со сценой планеты и 3D-модель тела).
- 15 языков, включая RTL (арабский) и CJK. Все тексты идут через `T(ru, en)`. Новые строки добавляй только так.
- **Меняй только слой оформления**: CSS, цветовые константы в JS, 3D-сцену, разметку шаблонов (когда без этого не обойтись). Логику, id, имена функций, структуру данных не трогай.
- Классы, на которых держится JS, сохраняй: `.card .hero .kpi .pill .ok .warn .bad .btns .on .tile .crew-card .cmd-card .mis .tabs #tabs #tind .tele .odo .arena .stim .radar .lcg .mgrid .enter .stg`.
- Тема одна, тёмная. `prefers-reduced-motion` обязателен. Контраст текста не ниже 4.5:1, элементов интерфейса не ниже 3:1. Статус никогда не передаётся одним цветом: цвет + форма + подпись.
- Шрифты должны иметь **кириллицу** (Google Fonts API проверен: у Fraunces, Newsreader, Instrument Sans, Bricolage Grotesque, Schibsted Grotesk её нет).

# Принцип

Перед правками сформулируй характер интерфейса одним предложением и держись его.
Для Astra Health: **«Заря над океаном»**. Ночной тёмно-синий, тёплый рассвет как единственный акцент, кремовая бумага бортового журнала. Три слова: тёплый, спокойный, точный.

# Тест на ИИшность: это запрещено

Если находишь что-то из списка, заменяй. Не «смягчай», а заменяй.

**Шрифты**
- Inter, Roboto, Arial, Open Sans, Poppins, Montserrat, DM Sans, Space Grotesk, Plus Jakarta, Outfit как «шрифт по умолчанию».
- Моноширинный шрифт (JetBrains Mono и подобные) для подписей и меток. Моно только для сырых данных (JSON, `pre`).
- Микролейблы КАПСОМ с трекингом .1–.3em. Это главный визуальный «почерк» ИИ-дашбордов.
- Гигантские цифры весом 200–300 как «hero metric». Лёгкие веса на мелком тексте.

**Цвет**
- Чистые `#000` и `#fff`, нейтральные серые без оттенка (`rgba(255,255,255,.1)` как граница, `#0b0b0b` как «чёрный»).
- Палитра Tailwind по умолчанию (`#3b82f6 #22c55e #ef4444 #a855f7 #06b6d4 #ec4899 #38bdf8 #60a5fa #facc15 #f59e0b …`).
- Циан/неон на тёмном, фиолетово-синие градиенты, градиентный текст.
- Серый текст на цветном фоне. Числа, окрашенные в цвет статуса, вместо числа цветом текста + маркера рядом.

**Поверхности**
- Стекломорфизм: `backdrop-filter: blur()` на всём. Заодно это дорого для GPU поверх анимированного canvas.
- Свечения: `box-shadow: 0 0 Npx currentColor`, светящиеся точки у статусов.
- Карточки в карточках, одинаковые карточки одной сеткой для любого контента, связка «рамка + inset-блик + большая тень».
- «HUD»-уголки на hover, цветная полоска слева у карточки, иконка в скруглённом квадрате над каждым заголовком.

**Движение**
- Один и тот же `fade-up 8px` на всё подряд.
- `bounce`, `elastic`, `spring`, отрицательные значения в `cubic-bezier`.
- Анимация `width`, `height`, `top`, `left`, `margin`. Только `transform`, `opacity` и (ограниченно) `filter`.
- Бесконечные пульсации «для живости» без смысла, hover длиннее 250 мс.

**Тексты**
- Эмодзи вместо иконок, восклицательные знаки, «seamless», «unlock», «elevate», «powered by AI» бейджи.

# Правила: делай так

## Типографика
- Пара: **Onest** (интерфейс, 300–700) + **Literata** (голос: логотип, заголовки разделов, номера, большие числа результата). Запасные кириллические: Golos Text, Geologica, Wix Madefor Text, Commissioner; антиква: Source Serif 4, Piazzolla, Alegreya, Spectral.
- Шкала (≈1.25): 12.5 / 14 / 15 (основной) / 19 / 22 / 32 / 48. **Минимальный размер 12px.**
- Веса: 400 текст, 500 интерфейс, 550–600 акценты. Не 200 и не 300 для мелкого.
- Заголовки и подписи пишутся обычным регистром. Подпись: 12.5px, цвет приглушённый, без трекинга.
- `text-wrap: balance` на заголовках, `text-wrap: pretty` на абзацах.
- `tabular-nums` только там, где цифры стоят столбцом (таблицы, одометр, поля ввода). Большие одиночные числа остаются пропорциональными.
- Длина строки не больше 65–70 знаков.

## Цвет (токены; используй их, не изобретай новые)
Нейтрали тонируем в оттенок бренда (262°, chroma .02–.035). Акцент занимает не больше ~10% площади.

```css
:root{
 --bg:oklch(.175 .028 262);   --bg2:oklch(.135 .03 265);
 --surf:oklch(.235 .03 262 / .74); --surf2:oklch(.29 .034 262 / .88); --solid:oklch(.225 .03 262);
 --ink:oklch(.935 .018 85);   /* тёплый кремовый, НЕ белый */
 --mut:oklch(.79 .025 255);   --dim:oklch(.66 .03 258);
 --line:oklch(.5 .04 262 / .42); --line2:oklch(.66 .06 262 / .62); --hair:oklch(.5 .035 262 / .22);
 --acc:oklch(.82 .105 62);    /* рассвет, единственный акцент */
 --acc2:oklch(.88 .085 70);   --accink:oklch(.2 .035 55); /* текст на акценте */
 --ok:oklch(.79 .13 158);     --warn:oklch(.86 .15 92);   --bad:oklch(.71 .17 24);
 /* серии данных (экипаж): проверены валидатором, см. ниже */
 --s1:#4e8ce6; --s2:#c0558d; --s3:#d16d23; --s4:#9b74d9;
}
```

- Статусы: `ok` круг, `warn` ромб, `bad` квадрат + подпись («Норма», «Внимание», «Действие»). Значение числа остаётся цветом текста, а статус показывает маркер рядом.
- **Серии данных проверяются скриптом, не на глаз.** Четвёрка `#4e8ce6, #c0558d, #d16d23, #9b74d9` на поверхности `#0a101d`: полоса светлоты, порог насыщенности, различимость для дальтоников (ΔE 14.3, цель ≥ 8) и для обычного зрения (ΔE 15.9, порог ≥ 15), контраст ≥ 3:1. Всё PASS. Если меняешь цвета, перепроверяй:
  `node validate_palette.js "#4e8ce6,#c0558d,#d16d23,#9b74d9" --mode dark --surface "#0a101d"`
- Цвет принадлежит сущности, а не позиции. Если астронавта скрыли с графика, остальные не перекрашиваются.
- Текст на акценте: `--accink`. Текст на цветной плашке статуса: цвет статуса на 15% тинте самого цвета.
- Фактура: тонкий шум (`feTurbulence`, opacity ~.07) поверх всего убирает «цифровую» плоскость. Он статичный, поэтому дёшево.

## Пространство и композиция
- Сетка 4px. Отступы **разные** по смыслу: 8 внутри группы, 14–16 между элементами, 28–32 между разделами. Одинаковый отступ везде = шаблон.
- **Разделы разделяем тонкой линией (`--hair`) и воздухом, а не коробками.** Поверхность (фон + радиус) получают только то, во что нажимают, и то, что важно: hero-блок статуса, KPI, плитки, карточки выбора.
- Радиусы: 10 для кнопок и полей, 16 для поверхностей, 999 для плашек. Не «всё 12».
- Не центрируй всё подряд. Левая колонка выровнена по левому краю, акцент создаётся масштабом и весом, а не рамками.
- Таблицы: только горизонтальные линии `--hair`, без зебры, шапка 12.5px приглушённым цветом.
- На ширине ≤ 1000px у разделов появляется поверхность (3D-фон под ними), веил усиливается так, чтобы текст читался поверх планеты.

## Компоненты
- **Кнопки:** одна главная кнопка на блок. Главная: сплошная заливка `--acc` + текст `--accink`, вес 600. Вторичная: `--surf` + линия. Выбранный чип: 16% тинт акцента + линия акцента. Нажатие: `translateY(1px) scale(.985)`. Фокус: `outline: 2px solid var(--acc); outline-offset: 2px`.
- **Плашки статуса:** без обводки и свечения. Тинт 15%, форма-маркер 7px, подпись 12.5px/550.
- **Поля:** подпись над полем, поле 10px радиус, фокус-кольцо как у кнопок, подписи разной длины не ломают выравнивание (grid `1fr auto`).
- **Табы:** подчёркивание 2px акцентом, активный ink, неактивный `--dim`. Индикатор двигается через `transform: translateX() scaleX()`.
- **Диалог:** фон `--bg2` 97%, радиус 20, тень тёмно-синяя (не `#000`), появление `scale(.965) → 1`.

## Графики (по правилам dataviz)
- Одна ось. Никаких двойных осей.
- Линия 2px, сетки и оси тонкие и сплошные (не пунктир), эталонная линия нормы может быть пунктиром.
- Подписи концов линий прямо у графика (название астронавта), легенда всё равно остаётся. Цвет в тексте не используем: подписи цвета `--mut`/`--ink`, а цвет несёт маркер.
- Область «личная норма»: серия 1 с прозрачностью .16.
- Область наведения у точки не меньше ~20px, подсказка показывает значение и отклонение. Каждое значение достижимо и без подсказки (таблица рядом).
- Одиночный ряд = цвет `--s1`, а не акцент интерфейса.

## Движение
Идея: **«наведение фокуса»**. Страница выходит из мягкого фокуса, как планета за ней.

- Кривые только ease-out: `cubic-bezier(.16, 1, .3, 1)` (основная), `cubic-bezier(.22, 1, .36, 1)`.
- Длительности: hover 150–250 мс; появление блока 700–800 мс; появление страницы 900 мс; заполнение полос и рисование линий 1000–1100 мс.
- Вход блока: `opacity 0→1`, `translateY(14px)→0`, `filter: blur(7px)→0`. Задержка на элемент 55–80 мс, потолок 12–14 элементов.
- Заголовок экрана входа: раскрытие через `clip-path: inset(0 0 100% 0) → inset(0)`.
- Полосы прогресса и заполнения: `transform: scaleX()`, не `width`. Линии графиков: `stroke-dashoffset` с `pathLength=1`.
- Бесконечная анимация допустима только когда есть смысл: ЭКГ, мигающий маяк спутника, «дыхание» статуса `bad`, медленное «дыхание» свечения планеты (16 с). Остальное статично.
- `@media (prefers-reduced-motion: reduce)`: выключить все анимации и переходы.

## 3D-сцена: Земля
- **Луны у Земли нет.** Вокруг оси планеты по орбите идёт **спутник**: орбита лежит внутри наклонённой группы Земли, поэтому плоскость орбиты всегда перпендикулярна оси (константа `INCL` задаёт небольшой наклон). За спутником тянется затухающий тёплый след, сам спутник вращается вокруг своей оси, маяк мигает. За планетой спутник скрывается корректно (depth test).
- Атмосфера: шейдер по параметру прицеливания луча (мягкое затухание наружу), у терминатора тёплая полоса рассвета. Плоские сферы с `BackSide` и фиксированной непрозрачностью не используем.
- Ночная сторона: огни городов (`earth-night.jpg`), мягкий терминатор. Дневная: тёплый свет, холодная «заливка» тени.
- Облака: отдельная прозрачная сфера, процедурная текстура, вращается чуть быстрее поверхности. Покрытие умеренное: заметные «комки» считаются браком.
- Свет: солнце `0xfdecd1` (тёплое), заливка `0x879fcb` (холодная). Не `0xffffff`.
- Звёзды: оттенки (кремовые, голубоватые, редкие янтарные), несколько слоёв с мерцанием разной частоты.
- Цвета 3D-сцены берём из токенов (hex-эквиваленты), потому что Three.js не понимает `oklch()`.
- Миссии (Луна, Марс) остаются, у Марса спутники Фобос и Деймос оставляем: они реальные.

## Тексты (если трогаешь)
- Коротко и конкретно: что произошло и что делать. Без «Давайте», без восклицаний.
- Статус называем словами («Норма», «Внимание», «Действие»), не только цветом и иконкой.
- Пустое состояние объясняет, что делать дальше.

# Приложение: вторая концепция «Бортовой журнал» (файл `astra-health-v13.html`)

Первая концепция («Заря над океаном», v12) тёмная и редакционная. Вторая меняет сам язык интерфейса, а не только раскраску. Если хотите её воспроизвести в другом проекте, добавьте к промпту этот блок.

- **Две цветовые области.** *Тёмная* (шапка, док, показания, экраны тестов, подсказки) и *бумажная* (основной лист и диалог). Компоненты берут только токены (`--ink --mut --dim --line --fill --fillink --ok --warn --bad --s1…s4`), поэтому перекрашиваются от области сами. Бумага: `oklch(.935 .02 85)`, чернила `oklch(.25 .045 262)`. Статусные цвета на бумаге глубокие (`ok .44`, `warn .48`, `bad .5` по светлоте), серии данных свои, проверены валидатором для светлой поверхности: `#3c79d1, #9e366f, #bf5914, #724aab` (ΔE 15.5 / 16.7).
- **Раскладка.** Не колонка с вкладками, а лист на сцене: лист слева (`position: fixed`, внутренняя прокрутка, радиус 30), планета справа свободна, показания (миссия, задержка, гравитация, доза) напечатаны крупными цифрами прямо на сцене справа внизу. На телефоне планета сверху, лист снизу как шторка.
- **Меню.** Вместо вкладок плавающий док с иконками. Эффект увеличения чисто на CSS (`:hover`, соседи через `+` и `:has()`), подпись появляется пилюлей над иконкой, активный пункт отмечен персиковым диском, который плавно переезжает (`translateX + scaleX`). Название раздела крупно в шапке листа. На телефоне док прокручивается и держит активный пункт по центру.
- **Кнопки.** Пилюли. Наведение: заливка чернилами слева направо (`background-size 0% → 100%`). Выбранный чип залит чернилами. Главная кнопка одна и персиковая.
- **Поля ввода.** Разлинованная форма: только нижняя линия, значение набрано антиквой 24px, фокус подчёркивает цветом.
- **Блоки.** Разделы с заголовком и линией под ним (как в журнале). Пастельные плитки для KPI и статусов, сплошной тёмный блок для командира. Игровые «экраны» остаются тёмными врезками в бумаге.
- **Движение.** Лист «опускается» (`translate + rotate .7deg`), блоки оседают снизу без размытия, заголовок раздела раскрывается маской при каждой смене раздела, док поднимается снизу, показания выплывают последними. Всё на `translate/scale/rotate/opacity`.
- **Правило проверки.** Подсказки (`#tp`, подпись дока) тёмные с тонкой светлой обводкой: светлая подсказка на светлом листе не читается.

# Приложение: третья концепция «Apple» (файл `astra-health-v14.html`)

Эта версия отвечает на три задачи сразу: стиль окон Apple, две темы и поддержка 15 языков без ИИ. Если переносите в другой проект, добавьте блок к промпту.

- **Окно как в macOS/iOS.** Матовый материал (`backdrop-filter: blur(40px) saturate(1.8)`), радиус 26, заголовок окна с «светофором» слева и названием раздела по центру. Кнопки работают: красная выходит из аккаунта, жёлтая сворачивает окно вниз (планета встаёт по центру), зелёная расширяет окно. На телефоне окно превращается в нижнюю шторку с «ручкой».
- **Больше места.** Окно тянется от 72px до низа экрана (24px), а док парит над его нижним краем, а не занимает отдельную полосу. Заголовок раздела перенесён в заголовок окна и больше не съедает высоту.
- **Группированные карточки (как в Здоровье и Настройках).** Скруглённые блоки без рамок, заголовок 17px/650, плитки показателей крупными цифрами, плашки статуса «капсулами». Кнопки: заливка системным синим для главного действия, серые капсулы для остального, выбранный чип залит синим. Поля ввода залитые, фокус даёт кольцо 3.5px.
- **Шрифт.** Системный стек: `-apple-system, "SF Pro Text/Display"`, затем Onest, затем системный. На устройствах Apple это настоящий SF Pro, на остальных Onest. Для китайского, японского, корейского, арабского и хинди подключены Noto Sans (подгружаются только нужные фрагменты).
- **Две темы.** Атрибут `data-theme` на `<html>`, выбор сохраняется, по умолчанию берётся тема системы. Все цвета заданы токенами, зарегистрированными через `@property`, поэтому тема переключается плавной анимацией. Контраст проверен: основной текст 13–17:1, вторичный не ниже 4.9:1. Сцена тоже меняется: ночной космос или светлое небо (звёзд нет, атмосфера рисуется обычным смешиванием, орбита тёмная). Переключатель: сегментированный контрол «солнце / луна» в шапке.
- **15 языков.** Все 366 строк интерфейса переведены и встроены в файл (словарь по индексам, никаких запросов к ИИ). Скрипт-проверка требует, чтобы в каждом переводе совпадали заполнители `{0}`, теги `<b>` и `<br>`. Язык выбирается по языку браузера.
- **Адаптация под письмо.** Для арабского `dir="rtl"`: окно уезжает вправо, планета влево, док, «светофор», стрелки и шкалы зеркалятся (логические свойства `inset-inline-*`, `margin-inline-*`). Для арабского, хинди, китайского, японского и корейского отключён отрицательный трекинг заголовков (он ломает лигатуры и иероглифы), увеличен межстрочный интервал для деванагари и арабской вязи, для латиницы и кириллицы включены переносы (`hyphens: auto`). Подписи вроде `/100` и `1–5` изолированы (`unicode-bidi: plaintext`), чтобы не переворачивались в RTL.
- **Проверка.** Все 15 языков прогнаны по всем экранам (астронавт и командир) в тёмной теме и на нескольких в светлой, на 1440×900 и 390×844: ни переполнений, ни ошибок консоли, ни непереведённых строк.
- **Осознанные исключения из автоаудита.** В этой версии аудит показывает 8 вхождений `backdrop-filter` (матовый материал окна, дока, шапки окна, диалога и контролов: это и есть стиль Apple) и 2 анимации ширины (растяжение окна кнопкой, а не «живая» анимация). Остальные пункты по нулям.
